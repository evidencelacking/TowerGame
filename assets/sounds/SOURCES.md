# Sound sources

Every wav here is either a CC0 recording by Kenney (https://kenney.nl, Creative Commons Zero 1.0,
https://creativecommons.org/publicdomain/zero/1.0/; each pack's own License.txt was checked and says CC0)
or by Joseph Sardin of BigSoundBank (https://bigsoundbank.com, CC0; the licence line was verified on each
sound's page, and credit is given though not required), converted to 22050 Hz mono 16-bit (one-shots
trimmed to under 1.5 s, loops cut to 3.5 s with the tail crossfaded into the head, levels roughly
matched), or a sound marked `generated`, which is original synthesis from `python tools/make_sounds.py`
(no existing audio read or sampled; used where no CC0 recording fit). Where the original is not an
obvious match for the name (the Theater clips are foley rustles, Intro/Santa!/Wedding are short chimes)
it is a stand-in until a better CC0 file is found. The BigSoundBank loops are cut from longer
recordings (Bird1-4 from different sections of Forest, Crowd1-2 and Resturant1-3 from different
sections of one recording each).

Edit this table by hand when a file is swapped; `tools/make_sounds.py` skips every name whose Pack is
not `generated`.
